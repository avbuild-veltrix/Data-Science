# 📖 About This Repository

Welcome to my **Exploratory Data Analysis (EDA)** repository.

This repository is a collection of EDA projects where I explore real-world datasets, clean messy data, visualize patterns, and extract meaningful insights using Python.

Each project focuses on improving my skills in:

* 🧹 Data Cleaning
* 📊 Data Visualization
* 📈 Statistical Analysis
* 🔍 Finding Hidden Patterns
* 💡 Data-Driven Storytelling

The goal is not just to create graphs but to understand the data and communicate useful insights.
