# 🌟 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Google Play Store Dataset**.

The primary objective is to clean, preprocess, analyze, and visualize the data to uncover meaningful insights about Android applications available on the Google Play Store.

---

# 📂 Dataset

The dataset contains information such as:

* 📱 App Name
* ⭐ Rating
* 💬 Reviews
* 📥 Installs
* 💲 Price
* 🎮 Category
* 📦 Size
* 📅 Last Updated
* 📲 Android Version
* 👥 Content Rating
* 🏢 Type

---

# 🧹 Data Cleaning

The dataset was cleaned by performing:

✅ Handling Missing Values

✅ Removing Duplicate Apps

✅ Cleaning **Installs** Column

✅ Cleaning **Android Version** Column

✅ Handling "Varies with device"

✅ Converting Text Columns into Numerical Format

✅ Data Type Conversion

---

# 📊 Exploratory Data Analysis

Some of the analyses performed include:

* 📈 App Category Distribution
* ⭐ Rating Distribution
* 📥 Most Installed Categories
* 🎮 Most Installed Games
* 💬 Most Reviewed Applications
* 💲 Free vs Paid Apps
* 👨‍👩‍👧 Content Rating Analysis

# 📌 Key Insights

✔ Most applications are Free.

✔ The Game category contains a large number of applications.

✔ Social and Communication apps receive very high review counts.

✔ Ratings are concentrated between **4.0 – 4.5**.

✔ Some apps have billions of installs while many have relatively few.
