### 📖 Project Overview

The Google Play Store dataset contains thousands of Android applications along with information such as ratings, reviews, installs, categories, prices, Android versions, and content ratings.

The objective of this project was not only to clean the data but also to uncover meaningful patterns about app popularity, user behavior, and market trends through Exploratory Data Analysis.

---

### 🔍 What Was Performed

✔ Data Cleaning

✔ Handling Missing Values

✔ Removing Duplicate Records

✔ Feature Engineering

✔ Cleaning Android Version Column

✔ Cleaning Installs Column

✔ Cleaning Price Column

✔ Data Type Conversion

✔ Statistical Summary

✔ Univariate Analysis

✔ Bivariate Analysis

✔ Data Visualization

---

### 📈 Key Questions Explored

* Which app categories dominate the Play Store?
* Which applications have the highest number of installs?
* Are free apps more common than paid apps?
* Which categories receive the highest number of reviews?
* How are app ratings distributed?
* Which Android versions are most commonly supported?
* Which content rating appears most frequently?
* What relationships exist between installs, ratings, and reviews?
